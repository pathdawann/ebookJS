1¿Qué es JavaScript?

El lenguaje de programación de la web. Si HTML es el esqueleto y CSS la piel, JavaScript son los músculos: menús que se abren, formularios que validan, datos que se actualizan sin recargar. Nació en 1995 (Brendan Eich, en Netscape) y su estándar se llama ECMAScript. Hoy corre en el navegador y también en servidores con Node.js.

A diferencia de HTML, JavaScript sí es un lenguaje de programación: tiene variables, condiciones, bucles y funciones.

2Variables y tipos de datos

Una variable es una caja con nombre. Usa const si el valor no cambia y let si cambiará. Evita var. Toca un valor para ver su tipo.

3Condicionales

El código toma decisiones con if, else if y else. Mueve la edad.

if (edad >= 18) {
  console.log("Mayor de edad");
} else if (edad >= 12) {
  console.log("Adolescente");
} else {
  console.log("Niño o niña");
}

4Funciones

Un bloque de código reutilizable. Recibe parámetros y devuelve un resultado con return. Las funciones flecha son una forma corta de escribirlas. Modifica y ejecuta.

7El DOM y los eventos

      
El DOM es el árbol de elementos que el navegador crea desde tu HTML. JavaScript puede leerlo y modificarlo, y reaccionar a eventos como clics o teclas. Estos dos ejemplos funcionan con el código que ves.

      
const boton = document.querySelector("#mas");
boton.addEventListener("click", () => {
  contador++;
  numero.textContent = contador;
});

    8Código asíncrono
    
      
    Algunas tareas tardan (pedir datos, esperar un temporizador). JavaScript no se detiene: las deja en cola y sigue. Predice el orden de salida y luego ejecuta.
    
      
    
      
    async function cargar() {
  try {
    const res = await fetch("https://api.ejemplo.com/datos");
    const datos = await res.json();
    console.log(datos);
  } catch (error) {
    console.error("No se pudo cargar", error);
  }
}
    
      
    fetch devuelve una promesa; await espera su resultado sin congelar la página.
