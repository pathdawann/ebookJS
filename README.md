## 🌱 Sobre Pathdawann y el aprendizaje continuo

**Pathdawann** es mi espacio de creación, divulgación y práctica constante en desarrollo web. Programar se aprende programando: escribiendo código, ejecutándolo al momento, leyendo la consola y entendiendo cómo la lógica transforma documentos estáticos en experiencias vivas. Esta guía cierra la trilogía base del desarrollo frontend.

## 🎯 ¿Qué encontrarás en esta guía?

1. **Fundamentos del lenguaje:** Variables (`const` y `let`), explorador interactivo de tipos de datos (`typeof`) y condicionales.
2. **Funciones y estructuras:** Funciones tradicionales y flecha, manipulación visual de **arrays** (`push`, `pop`, `map`, `filter`, `sort`) y objetos.
3. **El DOM y los eventos:** Ejemplos funcionales en vivo para escuchar clics, capturar teclas y modificar elementos del HTML dinámicamente.
4. **Asincronía y buenas prácticas:** Ejecución paso a paso de promesas, `setTimeout`, `async/await` y comparativas clave (`===` vs `==`).
5. **Autoevaluación:** Quiz interactivo con retroalimentación inmediata, reinicio y progreso guardado.

1. Clona este repositorio:

   *(Ajusta el nombre del repositorio si usaste otro en tu cuenta de GitHub).*
2. Abre `index.html` directamente en tu navegador o usa una extensión como *Live Server* en VS Code.
